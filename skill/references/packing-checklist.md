# 行李清单指南

## 清单结构

分三层：通用必带 + 目的地专属 + 天气适配。

### 通用必带（所有行程）

**证件**
- 身份证、驾驶证（自驾）、行驶证（自驾）
- 车险保单（自驾，电子+纸质）
- 银行卡、少量现金

**电子**
- 手机、充电器、充电宝
- 行车记录仪（自驾，确认正常工作）
- 车载充电器（自驾）

**药品**
- 肠胃药、感冒药、退烧药、创可贴
- 晕车药（按需）
- 个人常用药

**生活**
- 洗漱用品、换洗衣物
- 雨伞/雨衣
- 纸巾、湿巾
- 保温杯

### 自驾专属

- 备胎（确认胎压）、千斤顶、轮胎扳手
- 三角警示牌、反光背心
- 灭火器（有效期内）
- 拖车绳（5吨以上）、搭电线/应急启动电源
- 车载充气泵、补胎液
- 玻璃水、机油（少量备用）
- 离线地图（提前下载）

### 目的地专属

**高原（海拔 ≥3000m）**
- 氧气瓶/便携氧气
- 红景天（提前一周服用）
- 葡萄糖口服液
- 血氧仪（可选）
- 厚外套（昼夜温差大）
- 防晒霜（SPF50+）、墨镜、帽子

**海边**
- 防晒霜、泳衣、拖鞋
- 驱蚊液
- 防水手机袋

**山区/徒步**
- 登山鞋、登山杖
- 头灯/手电
- 能量棒/巧克力
- 防风外套

**冬季/北方**
- 防滑链（如去冰雪路段）
- 防冻玻璃水
- 厚衣物、暖宝宝

**亲子**
- 儿童安全座椅（自驾）
- 儿童药品、零食
- 推车/背带

### 天气适配

用 `maps_weather` 获取目的地天气后：
- 有雨 → 提醒带雨具，调整室内外行程比例
- 高温 → 提醒防暑、避开正午户外
- 降温 → 提醒加衣
- 大风 → 提醒山区/海边注意安全

## 景点专属贴士

在景点详情页单独标注，不混入通用清单。例如：
- 寺庙：不要穿短裙/吊带，保持安静
- 山岳：穿防滑鞋，带足水
- 博物馆：提前预约，带身份证
- 水上项目：带换洗衣物、防水袋

    "weather_note": "千岛湖3天均有小雨，建议带雨具"
  }
