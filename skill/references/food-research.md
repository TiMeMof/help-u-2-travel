# 美食检索指南

## 平台策略

- **优先小红书**：内容丰富，真实用户分享多，检索相对稳定。
- **抖音为补充**：可尝试浏览器搜索，但反爬强、需登录，抓不到就跳过。
- 两个平台结果合并去重。

## 检索关键词

每个城市用 2-3 组关键词：
- "城市名 美食推荐"
- "城市名 本地人吃的店"
- "城市名 特色小吃"
- （如已知区域）"区域名 美食"

## 营销号判断标准

**排除以下特征的内容：**
- 文案高度模板化（"家人们谁懂啊""绝绝子""YYDS"等堆砌，且内容空洞）
- 配图统一为专业棚拍/官方宣传图，无真实就餐场景
- 文末带明显硬广链接、团购引导、"私信领优惠"
- 账号名含"美食攻略""探店达人"等批量运营特征，且内容全是推广
- 多条不同店铺的帖子文案结构完全一致

**保留以下特征：**
- 有真实就餐照片（环境/菜品/小票）
- 提到具体排队时间、人均、踩雷经历
- 个人化表达，有优缺点评价
- 点赞/收藏数较高（小红书 ≥500 赞为有参考价值，≥2000 为热门）

## 输出格式

```json
{
  "foods": [
    {
      "name": "店名称",
      "type": "江浙菜/小吃/咖啡等",
      "must_try": ["招牌菜1", "招牌菜2"],
      "price_per_person": 80,
      "address": "具体地址或区域",
      "hours": "10:00-22:00",
      "source": "小红书",
      "heat": "高/中/低",
      "note": "排队久，建议错峰"
    }
  ]
}
```

## 执行方式

用浏览器自动化（browser-task）：
1. 打开小红书搜索页，输入关键词。
2. 滚动加载，截取前 10-20 条结果的标题、点赞数、摘要。
3. 点开高赞帖子查看内容，判断是否营销号。
4. 提取有效信息。
5. 抖音同理，如遇登录墙则记录"抖音检索受限，仅用小红书结果"。

**注意**：浏览器检索较慢（3-5 分钟），如用户时间紧可降级为通用搜索+知识汇总，并在方案中注明"美食为通用推荐，未做小红书深度检索"。
