# 住宿筛选指南

## 位置优先级

1. **景区步行可达**（≤1km）：适合行程集中在某个景区时。
2. **城内交通枢纽**：地铁交汇站、市中心、多个景点的几何中心。
3. **车站/机场附近**：仅用于到达日或离开日的过渡住宿。

## 价格筛选逻辑

1. 用户输入预算范围（如人均 200-500/晚）。
2. 粗筛范围 = 预算 ±20%（如 160-600），避免漏掉性价比高的稍贵选项。
3. 预检索 8-15 家酒店，HTML 前端用价格滑块做二次筛选。

## 检索方法

用通用搜索，关键词组合：
- "城市名 区域 酒店推荐 价格"
- "城市名 景区附近 酒店 性价比"
- "城市名 民宿 推荐 预算"

记录每家的：
- 名称
- 位置（区域/附近地标）
- 价格区间（元/晚）
- 评分（如有）
- 特色（亲子/江景/日式/新开业等）
- 来源链接

## 输出格式

```json
{
  "accommodations": [
    {
      "name": "某某酒店",
      "area": "西湖区",
      "near": "步行5分钟到西湖",
      "price_min": 350,
      "price_max": 580,
      "rating": 4.7,
      "tags": ["江景", "含早"],
      "note": "周末价格上浮约30%"
    }
  ]
}
```

## 注意事项

- 价格为检索时的参考价，必须标注"以实际预订为准"。
- 周末/节假日价格显著上浮，在 note 中提醒。
- 民宿和酒店都纳入，按用户偏好标注类型。
- 不做预订链接的实时校验，只提供酒店名和区域，用户自行搜索预订。
